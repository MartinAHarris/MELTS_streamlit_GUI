# MELTSdynamic Setup

This GUI uses the Windows build of MELTSdynamic included in /app.

Files:
- meltsdynamic.py
- meltsengine.py
- meltsstatus.py
- libalphamelts.dll
- libgsl*.dll
- libxml2-2.dll
- zlib1.dll

These must remain together.

No compilation is required.

If you wish to update MELTSdynamic:
- Download alphamelts-py from GitHub
- Replace the DLLs and Python modules
- Ensure version compatibility with Python
